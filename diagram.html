Key Object-Oriented Design Highlights for Marking Rubric

1. Inheritance & Polymorphism

  • Hierarchy: Entity → Organism → Animal → Herbivore, Carnivore, ApexPredator.
  • Polymorphic Dispatch: Engine updates and renders any Entity without type casting via update(...) and render(...).
  • Subclass Customization: Each consumer tier overrides sensing, threat assessment, food harvesting, and reproductive mutations.

2. Generics Usage

  • SpatialGrid<T extends Entity>: Generic spatial bucket queries with bounded type parameter and generic methods <E extends T> queryEntitiesNear(...).
  • Chromosome<T>: Generic trait container encapsulating allele types and Gaussian mutation bounds.
  • BoundedResource<T extends Number>: Type-safe upper/lower capacity bound tracker.

3. Robust Exception Handling

  • Domain exception hierarchy rooted at checked EcosystemException.
  • EntityOutOfBoundsException prevents world corruptions; caught and recovered in Engine loop.
  • InvalidConfigurationException and InvalidGenomeException ensure validated parameters before simulation bootstrap.
